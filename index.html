The Process I Followed to Host My Website

1. Purchased a Domain

Created an account on Cloudflare and purchased the domain dithi.us

2. Created My Website

Created HTML files for my website.

Added two pictures showcasing everyday activities: ironing clothes with care and hanging clothes to dry.

Added three links: Cloudflare, GitHub, and a Contact page.

3. Set Up GitHub Hosting

Created an account on GitHub.

Created a repository to host my website.

Uploaded my HTML files to the repository.

4. Connected My Domain

Configured my domain through the repository settings to connect it to my hosted website.

Published my website using my custom domain: https://dithi.us.
